# SoMuch - 搜索增强插件

一款用于增强 Typecho 自带搜索功能的插件

## 环境要求

- PHP 8.2 或更高版本
- Typecho 1.2 或兼容版本

## 功能亮点

搜索模式：可以配置常规搜索和仅搜索文章标题两种模式；

搜索过滤：可以设置一些分类黑名单，让其不被搜索到；

搜索限制：可以设定某个地址搜索频率限制；

## 使用说明

下载后将文件夹放置到插件目录下，然后启动插件，打开插件设置，根据文字提示设置即可。

## 行为说明

- **分类黑名单**只接受分类的 mid（设置页会列出现有分类及其 mid），填写标签 mid 或不存在的 mid 会在保存时报错。文章只要属于任意一个被屏蔽的分类就不会出现在结果里。
- **黑名单范围**默认「包含子分类」：屏蔽父分类时，其下所有子孙分类的文章也一并屏蔽；改为「仅精确匹配」则只屏蔽所填分类本身。
- **只搜索公开文章**：结果仅包含已发布（`publish`）、无密码、发布时间已到的文章。与 Typecho 自带搜索不同，已登录的作者也搜不到自己的私密文章和加密文章。
- **频率限制**按会话（Cookie）计数；对同一关键词翻页不计次，换关键词或直接访问其他关键词的分页都会计次。不保存 Cookie 的客户端（例如多数爬虫）不受此限制。
- **配置边界**：每页结果限制为 2–100 的偶数；频率次数限制为 1–1000；时间窗口限制为 1–86400 秒；自定义限制提示最多 200 个字符。旧配置超出范围时会在运行时自动收敛到安全范围。
- **限制提示**：留空时会根据当前限制时间和次数自动生成，避免修改频率参数后提示内容与实际规则不一致。
